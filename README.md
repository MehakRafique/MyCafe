# MyCafe – Café Website

MyCafe is a simple and interactive café website designed to provide users with information about the café, explore its offerings, and interact with its features. It is developed using HTML, CSS, and JavaScript to create a user-friendly and responsive web experience.

## Technologies Used
- HTML – Structure of the website.
- CSS – Styling and layout.
- JavaScript – Interactive functionality.

## Project Features
- Interactive café website.
- User-friendly interface.
- Dark mode functionality.
- Interactive form submission.
- Mouse hover effects.

## Project Structure

```text
MyCafe/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
